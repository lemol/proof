# @lemol/proof

An open helper for replaying a project’s scenarios on Playwright and writing
a versioned proof manifest: named steps, screenshots, video chapters and a trace.

The repository is being set up. The runner and manifest version 1 are planned
in the task list at `todo/TODO.md`; no implementation is available yet.

MIT licensed. A standalone Bun and TypeScript library, with its own lockfile
and CI when the first implementation lands. Releases use `proof@<version>` tags.
